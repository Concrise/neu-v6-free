东大 v6 免流配置生成器

校园网 IPv6 不计费、IPv4 计费。这里生成的 sing-box 配置会尽量让流量走 v6。所有处理都在你的浏览器里完成，不会上传任何内容。

1. 选模式、填信息

服务器脚本输出 把 setup.sh 最后输出的那段（从 entry_servers: 到节点列表结束）原样粘贴进来。
机场订阅内容（可选） Clash / mihomo 格式（订阅转换时选 Clash）。浏览器不能直接拉订阅链接，请在浏览器里打开订阅链接，把全部内容复制进来。节点地址是域名且有 IPv6 时会用 v6 连接（免费）。
高级设置（可选）

YAML 格式，覆盖前面的同名项。可用项见仓库里的 config.example.yaml，例如 display_names、hy2_brutal、v6_broken_cidrs。

2. 选每个分组默认走哪里

这里只是默认值，导入后在 App 或面板里随时可以改。

3. 下载配置

怎么导入
  1. Android / iOS / macOS：装 sing-box 官方 App，新建配置 → 本地 → 选下载的 json 文件。
  2. Windows：把 zip 解压到 C:\，得到 C:\neu-v6-free。在 v2rayN 里「添加自定义配置」，选其中的 config.json，内核选 sing-box，以管理员身份运行（TUN 需要）。分组面板：http://127.0.0.1:9090/ui。
  3. macOS 想开机常驻、带网页面板：用命令行版（node cli.js -p mac + mac/install.sh）。

生成的文件里有节点密码，不要发到群里。离开校园网（没有 IPv6）时，模式二在「① 免流隧道」选「不走隧道」。
