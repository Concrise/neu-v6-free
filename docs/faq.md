# 常见问题与工作原理

## 常见问题

**某个网站打不开 / 很慢 / 提示海外用户怎么办？**
面板「实时连接」搜索这个网站，看「实际出口」。点「改规则」换一个去向，例如改成「直连（v6 优先）」。1–2 秒生效。

**面板里的选择会保存吗？**
会。分组的选择存在 sing-box 的缓存里，重启后保持；「我的规则」存在规则目录的 `user-rules.json`。

**改了订阅、节点或服务器怎么生效？**
在面板「订阅与节点」「设置」里改完，点页面上方的「应用」：面板生成新配置、本地助手检查后安装并重启 sing-box，不需要管理员密码。
用命令行（`config.yaml`）管理设置的，重新生成后运行更新脚本（macOS `mac/update.sh`，Windows `update.bat`）。

**装了以后会不会把网弄断？**
不会一直断。安装和更新后都会自检，不通就自动撤回或换回旧配置；运行中本地助手每 30 秒检查一次，连续 3 次「经 sing-box 不通、绕过它能通」就暂停 sing-box，电脑回到普通网络。
随时可以在面板「概览」点「暂停」，或打开 `http://127.0.0.1:9091/`。

**退出别的代理软件后没网了？**
多半是它留下的系统代理还指向已经关掉的端口。安装脚本会自动关掉这种失效的系统代理；`HTTPS_PROXY` 这类环境变量要你自己删掉，或者在设置里把 `main_port` 设成同一个端口让 sing-box 接替。

**为什么只有第一次安装要管理员权限？**
sing-box 要接管全部流量（TUN），必须以管理员身份运行。安装时一并装好一个同样以管理员身份运行的本地助手；
以后的更新由它来检查和安装（检查配置里的文件路径都在安装目录内，再用 `sing-box check` 验证），所以更新脚本本身不需要权限。

**离开校园网（没有 IPv6）怎么办？**
第二部分：面板「免流服务器」选「不用服务器（离校时选）」，所有经服务器的流量改为直连。第一部分不受影响。

**服务器流量快用完了？**
「免流服务器」换一台；YouTube、Steam、苹果这类大流量分组临时改成「直连（v6 优先）」。

**怎么看省了多少？**
macOS 面板「📊 流量统计」：本月 v6 直连省下多少、经服务器免流省下多少（同时就是服务器的出站消耗）、校园网 v4 计费用了多少。

**可以和其他代理软件同时用吗？**
不行。两个都开 TUN 会互相抢流量，端口也会冲突。用这个之前先退出其他代理软件。

**我本来在用 Clash Verge / FlClash / v2rayN，机场订阅怎么办？**
这个工具本身就是一个完整的代理客户端：把订阅链接加到面板「📦 订阅与节点」里即可（Clash / mihomo、sing-box、v2rayN 格式都认）。
每个订阅自成一组「📦 订阅名」，里面可以自动选最快；在「国外网站」、AI、YouTube 等分组里选它。
模式二里这些落地默认先经你的免流服务器，所以连机场也不走计费的 IPv4。原来软件里的「规则 / 全局 / 直连」在面板「概览」里。

**订阅多久更新一次？**
在「订阅与节点」里点「更新」或「全部更新」。节点有变化时页面上方会提示「应用」。

**电脑上的网页、App 怎么走代理？**
不用设置：TUN 接管了整台电脑的流量。只有想让某个程序固定走某个出口时才用 `fixed_ports`。

## 工作原理

### 让流量尽量走 IPv6

- **IPv6 DNS 查国内域名**：很多国内 CDN 只对 IPv6 来源的 DNS 查询返回 IPv6 地址，所以国内域名用 `2400:3200::1` 查询。
- **有 IPv6 就直连 v6**：国内网站只要有 IPv6 地址，固定 v6 直连，排在所有按网站分的规则前面。
- **TUN 同时接管 v4 和 v6**：否则国外网站的 v6 会绕过代理从校园网直出。TUN 的 IPv6 用文档专用地址段而不是 ULA：
  按 RFC 6724，「ULA 源地址 → 公网 IPv6」排在 IPv4 后面，系统会先给 App 返回 IPv4，就判断不到网站有 v6 了。
- **连不通的 v6 网段直接拒绝**：有 AAAA 记录但从校园网 v6 实测不通的网段（例如腾讯一部分图片、视频节点）直接拒绝，App 马上回退 v4，不用干等超时。
- **v6 孪生域名**：有些服务把 IPv6 放在单独的域名上（如腾讯下载），把连接目标改到那个域名再 v6 直连。

### 第二部分：只有 IPv4 的流量也免费

- 电脑用 IPv6 连到自己的服务器（服务器的四个入站都监听 IPv6），服务器用 IPv4 访问目标网站。
- 国内域名的 A 记录用 fakeip：只有 IPv4 的国内网站连进来时带着域名，由服务器自己解析。否则传给服务器的是校园网解析出的国内 IP，从海外服务器连常常超时。
- 订阅里的国外节点默认也先经服务器（「（经服务器）」），所以国外流量同样免费。

### 例外分组

- **风控严格的**（登录、支付、银行、12306、学信网……）只能直连：经海外服务器会触发异地登录、验证码或失败。
- **按 App 整体处理的**（微信、网易云、英雄联盟……）：同一个 App 的所有连接一起决定，避免一部分被当成海外 IP。
- 国外类分组（AI、YouTube、流媒体……）可以单独选落地，例如 AI 固定一个干净的家宽 IP。

### 我的规则为什么能即时生效

每个去向对应一个 sing-box 本地规则集文件（`user-<去向>.json`），路由规则里引用它们。面板通过本地助手改写这些文件，
sing-box 发现文件变了会自动重新加载，不需要重启，也不需要重新生成配置。

### 为什么电脑上用本地规则集

规则集（哪些域名算国内、哪些算 AI……）在生成时下载，随配置一起装到本机。这样 sing-box 启动不依赖网络：服务器不通、不在校园网时也能正常启动。
手机上的 sing-box App 在线下载规则集并每天更新。
