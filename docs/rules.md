# 调整规则

有三种方式，从快到慢：

| 方式 | 在哪改 | 生效 | 适合 |
|---|---|---|---|
| 切换线路 | 面板「线路与规则」的「主要线路」「按应用单独设置」 | 立即，自动保存 | 换服务器、换落地、让某类流量改走直连 |
| 我的规则 | 面板「线路与规则」最上面「这个网站走哪里？」，或「设置 → 诊断 → 实时连接」→「改规则」 | 1–2 秒 | 某个网站、IP 或程序单独指定去向 |
| 写在设置里 | `config.yaml` 的 `group_defaults`、`custom_rules` | 重新生成并更新 | 手机上加规则；想把规则和设置放在一起管理 |

前两种不用运行任何命令。「我的规则」需要本地助手，macOS 后台服务和 Windows 版都有；手机和 sing-box 官方 App 用第三种。

## 分流顺序

每个连接从上往下匹配，**命中第一条就停**：

1. 固定端口进来的流量 → 各自固定的出口（见 `fixed_ports`）
2. 局域网、校园网内网（`neu.edu.cn`）、你自己的服务器 → 直连
3. **我的规则**，然后是设置里的 `custom_rules`
4. 风控严格的和按 App 的例外：🔐 登录·支付·银行、💬 微信、🎵 网易云、⚔️ 英雄联盟、⌨️ 豆包输入法
5. **国内网站有 IPv6 → 直连 v6**（固定，免费最快）
6. 国外类例外分组：🤖 AI、📺 YouTube、🍎 苹果、🎮 Steam、🎬 流媒体、✈️ Telegram……
7. 国内网站只有 IPv4 → 「国内仅 v4 网站」开关
8. 🎯 海外游戏
9. 剩下的全部 → 「国外网站」开关

所以「我的规则」比所有分组都优先：把一个网站加进去，就不再受分组影响。

## 线路（分组与开关）

面板「线路与规则」里：「主要线路」就是下面的总开关，「按应用单独设置」就是例外分组。

**总开关**决定大部分流量：

- **免流服务器**（第二部分）：所有「经服务器」的流量从哪台服务器、哪个协议出去。离校时选「不用服务器」。
- **国内仅 v4 网站**：没有 IPv6 的国内网站。选「免流服务器」= 免费但网站看到服务器 IP；选「直连 v4」= 计费，和不开代理一样。
- **国外网站**：国外网站最后从哪出去，也是兜底。

**例外分组**按 App 或网站类别单独决定，可选项按类别限定：登录·支付·银行只能直连（风控严格，经服务器会触发异地登录）；
App 类在直连和服务器之间选；国外类可以「跟随国外网站」或另选落地。

面板里每个选项都标了 <kbd>免费</kbd> / <kbd>计费</kbd>，点分组名可以看每个选项的说明并测延迟。选择存在 sing-box 的缓存里，重启后保持。

## 我的规则

![线路与规则](images/panel-rules.png)

在输入框里粘贴网址、域名、IP 或程序名，选去向，点「添加」。类型默认自动识别，也可以手动选：

| 类型 | 匹配 | 例子 |
|---|---|---|
| 域名（含子域名） | 这个域名和它所有子域名 | `bilibili.com` 匹配 `www.bilibili.com`、`api.bilibili.com` |
| 只这一个域名 | 完全相同的域名 | `api.example.com` |
| 域名里包含 | 域名里含这个词 | `openai` |
| IP / 网段 | IP 地址或网段 | `1.2.3.4`、`2001:db8::/32` |
| 程序（进程名） | 这个程序的全部流量 | Windows：`chrome.exe`；macOS：`Telegram` |

粘贴整个网址也行，会自动取出域名。中文域名会自动转换。

**去向**可以是：

- **直连**：「直连（v6 优先）」有 IPv6 走 v6（免费），没有走 v4（计费）；「直连 v4」只走 v4（计费，网站看到校园网 IP）。
- **服务器**：「免流服务器」，经自己的服务器出去（免费）。
- **跟随总开关**：跟随「国内仅 v4 网站」或「国外网站」当前的选择。
- **跟随分组**：跟随某个例外分组当前的选择。例如新出的 AI 网站，加进来选「跟随 🤖 AI」，以后在 AI 分组里换落地它也跟着换。
- **拒绝**：直接断开（屏蔽广告、跟踪）。

说明：

- 同一个值只能有一个去向，重复添加会改成新的去向。
- 已经建立的连接还按老规则走，刷新网页或重开 App 就会用新规则。从「实时连接」改规则时可以勾选「断开现有的相关连接」，让它们马上重连。
- 同一个网站被多条规则命中（例如同时有 `cloudflare.com` 和 `speed.cloudflare.com`）且去向不同时，按去向的固定顺序（直连 → 直连 v4 → 服务器 → 总开关 → 分组 → 拒绝）先匹配的生效。
  从「实时连接」改规则会自动删掉这条连接已经命中的旧规则，避免这种情况。
- 「导出」得到一个 JSON 文件，可以备份或在另一台电脑「导入」（导入会替换现有的全部规则）。
- 规则存在安装目录的 `rules/user-rules.json`，每个去向另有一个 sing-box 规则集文件 `user-<去向>.json`。卸载时默认保留，重新安装后接着用。

### 从实时连接改规则（设置 → 诊断 → 实时连接）

![改规则](images/panel-conn-modal.png)

「实时连接」里每条连接都显示目标、程序、为什么走这条路（命中了哪条规则）、实际出口和是否计费。勾选「只看计费的」可以快速找出花钱的流量。
点「改规则」，选按哪一级域名、按 IP 还是按程序匹配，再选去向即可。

## 写在设置里

### group_defaults：改分组的默认选择

面板里的选择会一直保存，`group_defaults` 只决定新安装时的默认值：

```yaml
group_defaults:
  "🤖 AI": "美国节点（经服务器）"     # 出口名必须是该分组里的选项，面板里能看到
  "📺 YouTube": "国外网站"
  "国内仅 v4 网站": "直连 v4"
```

### custom_rules：固定规则

所有平台都生效（手机上只能这样加规则），优先级仅次于「我的规则」。每条是 sing-box 路由规则的匹配条件加 `outbound`：

```yaml
custom_rules:
  - { domain_suffix: ["example.edu.cn"], outbound: "直连（v6 优先）" }
  - { domain_keyword: ["openai"], outbound: "🤖 AI" }
  - { process_name: ["Telegram.exe", "Telegram"], outbound: "免流服务器" }
  - { package_name: ["com.example.app"], outbound: "直连 v4" }        # 安卓按包名
  - { ip_cidr: ["203.0.113.0/24"], outbound: "直连（v6 优先）" }
  - { rule_set: "geosite/category-ads-all", outbound: "拒绝" }        # MetaCubeX 的规则集
```

- `outbound` 可以是任意出口、总开关、分组名，或「拒绝」。写错了生成时会报错并提示。
- 同一条里不同种类的条件是「且」（例如进程名 + 域名 = 这个程序访问这个域名），同种类的多个值是「或」。
- 本平台不支持的条件会自动去掉：iOS 不能按进程，只有安卓有包名。
- `rule_set` 写 `geosite/名字` 或 `geoip/名字`，名字见 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat/tree/sing/geo)。

改完重新生成并更新（macOS `mac/update.sh`，Windows `update.bat`，手机重新导入）。

### 加一个新的例外分组

分组定义在 [lib/groups.js](../lib/groups.js) 的 `SERVICE_GROUPS`：名字、说明、匹配规则（规则集、域名、各平台的进程）、可选项类别和默认值。
照着已有的分组加一项即可；觉得别人也用得上，欢迎提 PR。
